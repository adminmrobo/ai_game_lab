# AI로 풀어보는 게임 시리즈

연구실 식구 하루·시아·모아가 플레이어로 나서서 게임을 직접 풀어 보고, AI가 같은 게임을 어떻게 푸는지 따라가는 연구실 해설 시리즈입니다.

- 시리즈 목차: https://adminmrobo.github.io/ai_game_lab/
- 글: 안상선 ((주)M-Robo 대표) · [저자 소개](https://adminmrobo.github.io/who_am_i/who_am_i.html)

| 편 | 게임 | 주제 | 페이지 |
|---|---|---|---|
| ① | 스도쿠 | AI는 스도쿠를 어떻게 풀까? — 에너지 모델(그릇 만들기·공 굴리기) | [sudoku/](https://adminmrobo.github.io/ai_game_lab/sudoku/) |
| ② | 대항해시대 4 코인 게임 | AI는 필승법을 어떻게 찾을까? — 뒤에서부터 따지기(게임 나무)·스스로 두며 배우기(Q 학습)·모든 수 찾기(넓이 우선 탐색) | [coin/](https://adminmrobo.github.io/ai_game_lab/coin/) |
| ③ | 대항해시대 2 다이스 | AI는 확률로 어떻게 고를까? — 모든 경우 세기(경우의 수)·굴려 보며 어림하기(몬테카를로) | [dice/](https://adminmrobo.github.io/ai_game_lab/dice/) |
| ④ | 대항해시대 2 블랙잭 | AI는 받을지 설지 어떻게 정할까? — 딜러 따지기·기댓값 표(벨만)·해 보고 평균 내기(몬테카를로 학습) | [blackjack/](https://adminmrobo.github.io/ai_game_lab/blackjack/) |
| ⑤ | 슬라임 레이스(리니지 슬라임 경주장 각색) | 강화학습은 모르는 확률을 어떻게 배울까? — 탐험과 활용(ε-탐욕)·덤 주기(UCB)·상태 보고 고르기(맥락 밴딧) | [slime/](https://adminmrobo.github.io/ai_game_lab/slime/) |
| ⑥ | 미로 | 준비 중 | — |

build/game.js · game.css · kgcommon.py · make_temp_covers.py   ③~⑤ 공통(게임 화면 도우미, 임시 표지, 지식 색인 도우미)

## 빌드와 검산
```
python3 build/sudoku/kg_defs.py   # ① 지식 색인·참고문헌·서지
python3 build/coin/kg_defs.py     # ②
python3 build/dice/kg_defs.py; python3 build/blackjack/kg_defs.py; python3 build/slime/kg_defs.py   # ③~⑤
node code/check_dice.js; node code/check_blackjack.js; node code/check_slime.js   # ③~⑤ 검산 + nums.json 기록(빌드 전에)
node build/build.js               # 목차와 모든 게임 페이지
node code/check_sudoku.js         # ① 정답 유일성, 짝 수, 그릇 모양, 벌점표 학습, 레이스 40판
node code/check_coin.js           # ② 지는 자리 1+4N, Q 학습 판 수별 결과, 동전 옮기기 최단 2수, 공략글 검산
```
③~⑤ 본문의 `@@이름@@` 숫자는 검산 스크립트가 적은 `nums.json`에서 채웁니다. 표지 그림 `<게임>/img/<게임>_cover.webp`(+`_960`)을 넣으면 빌드가 임시 표지·목차 썸네일을 그림으로 바꿉니다.
새 게임을 더할 때는 `build/<게임>/`에 원본을 두고 `build/build.js`의 `GAMES` 목록과 `build/series/index.src.html`의 카드를 함께 고칩니다.
